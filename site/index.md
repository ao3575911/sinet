SINet is a Go social CLI and PostgreSQL API prototype. Your terminal. Your network.

Start with [Quickstart](quickstart.html), then explore [Connectors](connectors.html),
[Architecture](architecture.html), [Operations](operations.html), [Security and privacy](security-and-privacy.html),
[Validation](validation.html), [Contributing](contributing.html) and [Roadmap](roadmap.html).

The account journey is real: email OTP, atomic unique handle, public profile, room, private
notes, a reviewed installed connector, explicit grant, audited agent tool use and revocation.
Echo is deterministic. Live production email/model/remote services require configuration.
No uploaded code, hosted shell, host filesystem/USB access, active inbox or wallet is shipped.
