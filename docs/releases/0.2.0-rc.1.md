# SINet 0.2.0-rc.1 — candidate notes

Prepared 22 October 2026 for source review; no release, tag, npm/PyPI package or live
connector approval is published. Five historical tags and published 0.1.1 bytes remain
unchanged. This minor-feature prerelease follows the repository SemVer rules.

Users of current source can link an external Ethereum EOA through an account/origin-bound,
one-use wallet proof, manage private email drafts and explicitly prepare a Gmail review
link. These existing unreleased features are preserved, including export/deletion and
the browser signing helper. No funds move and SINet does not send mail or sync Gmail.

The public GitHub connector now has a deterministic CLI/TUI journey: inspect/install a
reviewed pinned version, grant repository_summary, review gateway plus GitHub and exact
owner/repository disclosure, approve once, invoke through the personal agent, inspect
bounded validated facts/audit and revoke/uninstall. No model credentials are required.
API and CLI revalidate the gateway's public facts; hostile instructions remain inert
text. Consent also expires if it waits on the account lock past its deadline.

Gateway deployment preparation includes a non-root/read-only container, capability and
resource limits, a local health probe, monitoring requirements and rollback instructions.
Active build and CI pins move to Go 1.27.3 after validation found a reachable x509 advisory
in 1.27.2. The patched scanner reports no reachable findings; the unused x/crypto OpenPGP
package still has a module-level advisory. See the [evidence ledger](0.2.0-rc.1-validation.md).

The live GitHub journey is **not verified**. Next action: provision controlled public
HTTPS hosting, capture ownership/TLS/operational evidence, then submit the real immutable
manifest for a separate operator review and run the live two-account journey. No placeholder
is preapproved. Independent security review, production operations, load/restore and native
macOS/Windows runtime qualification remain separate release gates (#2–#6). Wallet-extension
and Gmail delivery tests also remain external; local browser tests use a mocked provider.
