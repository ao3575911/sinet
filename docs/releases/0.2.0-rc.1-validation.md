## Failures found and resolved

The first integration run rejected an overlong fixture operation description under the
existing manifest's 280-character limit. Shortened the fixture; did not broaden the schema.
The existing PTY script matched "Wallet, email and services" inside dashboard output before
its submenu opened. Anchored the submenu title and added failure cleanup; rerun passed.
Queued consent was checked against transaction-start now(), which could accept an approval
that expired while waiting. Changed only the consumption predicate to clock_timestamp()
and added a real PostgreSQL lock-wait regression; passed.

GO-2026-6809 (x509 certificate verification), fixed from Go 1.27.3. Updated active build,
CI and recommended toolchain pins and added a go.mod toolchain directive. The rerun:

the vulnerability database; prior policy-denied scans remain historical records.
