# Roadmap and release gates

Implemented milestones cover bootstrap, identity, social/workspace, governed connectors,
optional model chat, quotas, CLI onboarding and operating controls. The prototype is not a
public production certification.

Public-release work is tracked in labelled issues:

- [#2 Independent security review](https://github.com/ao3575911/sinet/issues/2)
- [#3 Production mail/TLS/model setup](https://github.com/ao3575911/sinet/issues/3)
- [#4 Real remote connector and reconciliation](https://github.com/ao3575911/sinet/issues/4)
- [#5 Load, moderation and encrypted recovery](https://github.com/ao3575911/sinet/issues/5)
- [#6 Native platform UX and keychain](https://github.com/ao3575911/sinet/issues/6)

Business namespaces, OAuth/MCP, isolated compute, USB/local bridges, wallets and mobile are
later tracks. They are not advertised as functioning capabilities.
